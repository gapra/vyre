# Kawaii

Cute Japanese-inspired aesthetic: soft pastels, rounded everything, friendly faces.

## When to use

- Kid apps
- Niche cute brands

## When NOT to use

- Most products

## Do

- ✅ Soft pinks/blues
- ✅ Rounded mascots
- ✅ Friendly micro-copy

## Don't

- ❌ Use unironically for B2B

## Recipe (CSS)

```css
background: oklch(95% 0.06 340);
border-radius: var(--vyre-radius-3xl);
```

## Required tokens

- `palette.kawaii`

## Performance cost

`low` — no significant cost

## Accessibility

Test pastel contrast.
