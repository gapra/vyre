# Synthwave

80s sunset gradients with grid horizons and neon accents.

## When to use

- Music apps
- Retro themes
- Hero sections

## When NOT to use

- Serious products

## Do

- ✅ Magenta-to-purple gradient
- ✅ Neon outlines
- ✅ Pixel grid backgrounds

## Don't

- ❌ Use for dashboards
- ❌ Combine with flat

## Recipe (CSS)

```css
background: linear-gradient(180deg, oklch(20% 0.15 270) 0%, oklch(60% 0.28 320) 100%);
color: oklch(95% 0.04 60);
```

## Required tokens

- `palette.synthwave`

## Performance cost

`medium` — reasonable for most contexts

## Accessibility

Use with strong text overlays.
