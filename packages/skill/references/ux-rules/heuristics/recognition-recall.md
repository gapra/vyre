# Recognition Rather Than Recall

> Minimize memory load by making options, actions, and information visible.

**Severity:** `medium`

## Rule

Show, don't make users remember. Recently-used items, autocomplete, contextual help, persistent labels.

## Do

- Persistent labels above inputs (not placeholder-only)
- Show breadcrumbs for deep navigation
- Recently-used items in pickers

## Don't

- Placeholder-only labels (vanish on focus)
- Force users to memorize codes or IDs
