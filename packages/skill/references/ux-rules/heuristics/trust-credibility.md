# Trust and Credibility

> Polish, transparency, and predictability build trust. Cheap-looking UI loses users.

**Severity:** `high`

## Rule

Consistent typography, proper alignment, no layout shifts, honest copy. Show provenance for AI-generated content.

## Do

- Eliminate CLS (cumulative layout shift)
- Label AI suggestions clearly
- Use real numbers, not 'lorem ipsum' in production

## Don't

- Misalign elements 'just by 2px'
- Hide AI involvement in user-facing content
