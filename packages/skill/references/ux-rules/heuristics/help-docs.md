# Help and Documentation

> Even better if no help is needed, but provide it for complex tasks.

**Severity:** `low`

## Rule

Contextual help over manuals. Tooltips for non-obvious actions. Empty states teach.

## Do

- Tooltip on icon-only buttons
- First-run tours for new features
- Helpful empty states with CTAs

## Don't

- Hide all help in a separate manual
- Tooltip every single button (creates noise)
