# Respect User Autonomy

> Don't dark-pattern users into actions they didn't choose.

**Severity:** `high`

## Rule

No fake urgency, no confirm-shaming, no pre-checked opt-ins for risky actions, no roach-motel cancellation flows.

## Do

- Symmetric difficulty: cancellation as easy as signup
- Honest defaults
- Clear opt-out for marketing

## Don't

- 'Are you sure you want to miss out?' decline button
- Hide unsubscribe in 6pt gray text
- Pre-check newsletter opt-in
