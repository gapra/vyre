# Flexibility and Efficiency of Use

> Accelerators for experts that don't get in the way of novices.

**Severity:** `medium`

## Rule

Provide keyboard shortcuts, command palettes, bulk actions for power users. Hide them behind discoverable affordances.

## Do

- Cmd+K command palette
- Bulk select with shift-click
- Keyboard shortcuts in tooltips

## Don't

- Require memorizing shortcuts to be productive
- Hide all power features
