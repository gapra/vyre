# Aesthetic and Minimalist Design

> Remove what isn't needed. Every extra element competes for attention.

**Severity:** `medium`

## Rule

Default to less. Add only what serves the task. Decorations dilute focus.

## Do

- Remove decorative dividers between aligned items
- Cut secondary info to a 'show more'
- Question every icon's necessity

## Don't

- Add borders, shadows, and gradients to one element
- Decorate empty states with unrelated illustrations
