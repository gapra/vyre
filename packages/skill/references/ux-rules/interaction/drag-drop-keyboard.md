# Drag-and-Drop Has Keyboard Equivalent

> Every drag-drop interaction has buttons or shortcuts for keyboard users.

**Severity:** `medium`

## Rule

Up/Down buttons or 'Move to...' menu. Announce changes via live regions.

## Do

- 'Move up' / 'Move down' buttons next to draggable items
- Cmd+↑/↓ shortcuts

## Don't

- Drag-only reordering with no alternative
