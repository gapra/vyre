# Labels, Not Placeholder-Only

> Persistent visible labels. Placeholders are hints, not labels.

**Severity:** `high`

## Rule

Placeholder vanishes on input — users forget what the field is. Pair label + optional placeholder for examples.

## Do

- Label above input, placeholder for example format
- 'Email address' label + 'name@example.com' placeholder

## Don't

- Placeholder-only labels
- Floating labels in critical forms
