# Button Labels Describe Action

> Buttons say what they do, in user terms.

**Severity:** `high`

## Rule

Verb-first ('Save changes', 'Delete project', 'Send invite'). Avoid generic 'OK' / 'Submit' / 'Click here'.

## Do

- 'Delete project' instead of 'OK'
- 'Send invite' instead of 'Submit'

## Don't

- 'OK' on a destructive confirm
- 'Click here' for links
