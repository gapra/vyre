# Error Message Anatomy

> Problem + cause + solution. No blame. No codes alone.

**Severity:** `high`

## Rule

Structure: 'X happened because Y. Try Z.' Friendly but precise. Inline near the source.

## Do

- 'We could not save your changes. Check your connection and try again.'
- Suggest specific actions

## Don't

- 'You entered the wrong thing.' (blames user)
- 'Error.' (no info)
