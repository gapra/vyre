# Loading Copy

> Brief, calm. 'Loading...' is fine. Long loads can show what's happening.

**Severity:** `low`

## Rule

Don't use loading copy to entertain. Status > novelty.

## Do

- 'Loading your dashboard...'
- 'Saving... this may take a moment'

## Don't

- 'Reticulating splines...'
- Loading messages that lie
