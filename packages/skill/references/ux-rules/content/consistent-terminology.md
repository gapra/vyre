# Consistent Terminology

> Use the same word for the same concept everywhere.

**Severity:** `medium`

## Rule

Don't switch between 'projects' / 'workspaces' / 'spaces' for the same thing. Maintain a glossary.

## Do

- Pick 'project', use it everywhere
- Glossary for design + engineering

## Don't

- Synonyms for the same UI concept across screens
