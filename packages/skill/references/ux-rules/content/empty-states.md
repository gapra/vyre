# Empty States Teach

> Empty states are onboarding moments. Tell user what goes here, why, and how to start.

**Severity:** `medium`

## Rule

Headline (what) + body (why useful) + CTA (how to start). Optionally illustration.

## Do

- 'No projects yet. Create your first project to organize your work.' + 'New project' button
- Friendly, brief illustration

## Don't

- Blank page with nothing
- 'No data' as the entire empty state
