# Full Keyboard Operability

> Every interactive element must be reachable AND operable by keyboard alone.

**Severity:** `high`

## Rule

No mouse-only interactions. Custom controls implement standard key bindings (Space, Enter, Arrow keys, Esc).

## Do

- Enter activates buttons, Space toggles checkboxes
- Esc closes modals/menus
- Arrow keys navigate menus and tabs

## Don't

- Hover-only menus with no keyboard equivalent
- Drag-and-drop with no keyboard alternative
