# Skip Navigation Link

> Provide a 'Skip to main content' link as the first focusable element.

**Severity:** `medium`

## Rule

Visually hidden until focused. Lets keyboard users bypass repeated navigation.

## Do

- First focusable element on every page
- Reveals on focus with high contrast

## Don't

- No skip link at all
- Skip link that's hidden even when focused
