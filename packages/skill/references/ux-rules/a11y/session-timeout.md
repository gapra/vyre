# Session Timeout Warnings

> Warn users before timeout; offer to extend session.

**Severity:** `medium`

## Rule

Don't auto-logout without warning. Provide ≥20s warning with one-click extension.

## Do

- Modal warning at T-1 minute
- Single-click extend button

## Don't

- Silent timeout that loses form data
- Re-login prompt with no warning
