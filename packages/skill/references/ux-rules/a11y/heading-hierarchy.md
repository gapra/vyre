# Heading Hierarchy

> One h1 per page; never skip levels (h2 → h4).

**Severity:** `high`

## Rule

Headings are landmarks for screen reader users. Hierarchy must reflect document structure, not visual styling.

## Do

- One <h1> per page (page title)
- h2 for major sections, h3 for subsections
- Use CSS to size, not heading level

## Don't

- h3 chosen because 'h1 looks too big'
- Skip from h1 to h4
- Multiple h1s on a single page
