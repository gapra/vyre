# Touch Target Size

> Interactive targets ≥44×44px (iOS) / 48×48dp (Material).

**Severity:** `high`

## Rule

Apply to all touch UI: buttons, links, icons, form controls. Smaller is OK only if non-essential AND has 24px clear space around.

## Do

- 44px minimum height for touch buttons
- Pad icon buttons to reach 44px

## Don't

- 12px close-X icons in modals
- Tiny tap targets in mobile nav
