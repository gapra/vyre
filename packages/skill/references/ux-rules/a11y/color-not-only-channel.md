# Color Is Not the Only Channel

> Don't rely on color alone to convey meaning.

**Severity:** `high`

## Rule

Pair color with icon, text, pattern, or position. Color-blind users (~8% of men) miss color-only cues.

## Do

- Red error + ⚠ icon + 'Error:' prefix
- Status badges with text label
- Underline links, don't just color them

## Don't

- Red/green diff with no icons or labels
- Required fields marked only with red asterisk
