# Non-Text Contrast

> UI components and graphical elements need ≥3:1 against adjacent colors.

**Severity:** `high`

## Rule

Buttons, form borders, focus rings, icons that convey info — all need 3:1 minimum.

## Do

- Form input borders ≥3:1
- Toggle switch states distinguishable by contrast

## Don't

- Whisper-thin gray borders on white
- Disabled-looking inputs that are actually active
