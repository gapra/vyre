# No Auto-Play Looping Motion

> Looping animations next to text are distracting; pause when user is reading.

**Severity:** `medium`

## Rule

Auto-playing video/animation should pause off-screen, allow pause, and never loop indefinitely.

## Do

- Pause hero video when out of viewport
- User-controllable pause button

## Don't

- Looping background video with no control
- Animated GIFs in body text
