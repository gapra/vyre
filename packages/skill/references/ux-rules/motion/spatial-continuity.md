# Spatial Continuity

> Animate elements between states so users track them; don't snap-cut.

**Severity:** `medium`

## Rule

Detail views slide from list item, modals scale from trigger, items reorder smoothly.

## Do

- Shared-element transitions (FLIP)
- Source-aware modal animations

## Don't

- Modals fade in from nowhere when triggered by a specific button
- Items teleport on reorder
