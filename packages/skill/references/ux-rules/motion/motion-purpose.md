# Motion Has Purpose

> Animation communicates: state changes, hierarchy, spatial relationships. Decorative motion is noise.

**Severity:** `high`

## Rule

Every animation answers a question: what changed, where did it come from, what should I look at? If it doesn't, remove it.

## Do

- Slide-in from where item came from
- Fade-out on dismiss
- Scale-up on focus to draw attention

## Don't

- Bounce every element on hover
- Animations that delay user actions
