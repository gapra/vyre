# Focal Point

> Every screen needs one primary focal point. More than one creates competition.

**Severity:** `high`

## Rule

Use size, color, contrast, or position to establish ONE primary action or element. Secondary actions support, not compete.

## Do

- One filled primary button per view
- Use accent color sparingly for the most important CTA

## Don't

- Five 'primary' buttons in one toolbar
- Use the brightest color on every interactive element
