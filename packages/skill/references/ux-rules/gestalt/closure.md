# Closure

> The mind completes incomplete shapes; you don't need to draw every line.

**Severity:** `low`

## Rule

Implied boundaries (whitespace, alignment) are often enough. Don't add borders to every container.

## Do

- Use whitespace to imply card edges in airy layouts
- Trust alignment over borders

## Don't

- Border every single div
- Add dividers between every list item
