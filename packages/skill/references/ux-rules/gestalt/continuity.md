# Continuity / Good Continuation

> The eye follows smooth lines and curves; align elements to continuous axes.

**Severity:** `medium`

## Rule

Align elements on a shared baseline, edge, or grid line. Visual jumps break flow and hurt scanability.

## Do

- Align form labels to a consistent left edge
- Use baseline grids for typography
- Maintain consistent column edges

## Don't

- Stagger button heights for 'visual interest'
- Mix text alignment within one column
