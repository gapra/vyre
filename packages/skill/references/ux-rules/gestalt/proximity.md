# Proximity

> Group related items by spatial closeness; separate unrelated items with whitespace.

**Severity:** `high`

## Rule

Items closer together are perceived as related. Use spacing to communicate hierarchy and grouping before resorting to borders or backgrounds.

## Do

- Use 4-8px gaps for tightly related items (label + input)
- Use 16-24px gaps between distinct groups
- Use 32-64px gaps between sections

## Don't

- Surround every group with a border 'just to be safe'
- Use equal spacing for related and unrelated items
- Compensate for poor proximity with louder colors
