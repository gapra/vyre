# Similarity

> Visually similar elements are perceived as related, even when far apart.

**Severity:** `high`

## Rule

Use consistent shape, size, color, and typography for elements that share function. Break similarity only to signal a meaningful difference.

## Do

- Make all primary buttons identical across the app
- Use one shape language for icons (filled OR outlined)
- Reserve color variation for status, not decoration

## Don't

- Mix button styles for the same action type
- Use 5 different icon styles in one screen
- Vary stroke width arbitrarily across icons
