# Common Fate

> Elements moving together are perceived as related.

**Severity:** `medium`

## Rule

Animate grouped elements with shared timing and direction. Stagger only to imply sequence, not for decoration.

## Do

- Animate list items with a 30-50ms stagger when entering
- Move related elements with the same easing curve

## Don't

- Animate every item with a different curve
- Use random delays that feel chaotic
