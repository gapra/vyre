# Visual Hierarchy

> Establish a clear reading order with size, weight, color, and spacing.

**Severity:** `high`

## Rule

Three levels of hierarchy is usually enough: primary (what), secondary (context), tertiary (details). More than five levels is noise.

## Do

- Use type scale to differentiate H1/H2/H3
- Reserve bold weight for emphasis, not decoration

## Don't

- Bold every heading AND label AND value
- Use 7 type sizes in one card
