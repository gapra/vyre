# Success State After Submission

> Confirm submission clearly. Don't just refresh.

**Severity:** `medium`

## Rule

Inline success message, redirect to confirmation page, or update state with clear feedback.

## Do

- 'Thanks! Check your email for next steps.'
- Confirmation page with order details

## Don't

- Silent refresh
- Replace form with empty form (looks like nothing happened)
