# Password UX

> Show/hide toggle. Real-time strength feedback. Allow paste.

**Severity:** `high`

## Rule

Show password toggle reduces errors. Real-time strength helps users hit requirements. NEVER block paste (kills password managers).

## Do

- Eye icon to toggle visibility
- Real-time requirement checklist
- Allow paste

## Don't

- Block paste on password fields
- Require obscure rules ('one Cyrillic letter')
- Force password change every 30 days (NIST advises against)
