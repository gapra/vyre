# Default to Single Column

> Single-column forms are faster to scan and complete.

**Severity:** `high`

## Rule

Multi-column only for short related fields (first/last name, city/state/zip). Default to one column.

## Do

- Single column body forms
- Pair short related fields side-by-side

## Don't

- Two-column forms with long fields zigzagging the eye
