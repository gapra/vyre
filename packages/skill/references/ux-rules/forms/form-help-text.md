# Helpful Help Text

> Persistent help text for non-obvious fields, below the input.

**Severity:** `medium`

## Rule

Format hints, length requirements, why it's needed. Keep it short and visible.

## Do

- 'Password must be 8+ characters' below the input
- 'We will never share your email' for sensitive fields

## Don't

- Hidden tooltips for required hints
- Help text that vanishes on focus
