# Mark Required Clearly

> Mark required fields with text 'Required' or '*' + legend. Don't rely on color alone.

**Severity:** `high`

## Rule

Some forms mark required, some mark optional. Pick one based on which is fewer. State the choice clearly.

## Do

- 'Email *' with legend '* Required'
- Mark optional if most fields are required

## Don't

- Red asterisk only (color-only signal)
- Inconsistent marking style
