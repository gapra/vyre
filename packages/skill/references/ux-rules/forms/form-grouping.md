# Group Related Fields

> Use headings, fieldsets, or whitespace to group related inputs.

**Severity:** `medium`

## Rule

Cognitively chunk: contact info, address, payment. Each group has a clear heading.

## Do

- <fieldset><legend>Shipping address</legend>...</fieldset>
- 16-24px spacing between groups

## Don't

- 50 fields in a flat list
- Random ordering
